LESSON 01

JavaScript Introduction

JavaScript is a programming language used to add behavior to web pages. It can respond to user actions, update page content, and work with data. 

console.log("Hello, world!");
LESSON 02

Adding JavaScript

Place scripts in a separate file and use defer so the browser parses the page before running the script. 

<script src="app.js" defer></script>
LESSON 03

Variables

Use const for bindings that will not be reassigned and let when reassignment is needed. Avoid declaring new variables with var in modern code. 

const learner = "Alex";
let lessonsCompleted = 0;
lessonsCompleted += 1;
LESSON 04

Data Types

JavaScript values include strings, numbers, booleans, objects, and undefined. Use null to represent an intentional absence of a value. 

const title = "HTML basics";
const score = 10;
const finished = false;
LESSON 05

Operators

Operators calculate values and compare them. Use strict equality (===) to compare both value and type in most cases. 

const total = 4 + 6;
const passed = total >= 8;
console.log(passed === true);
LESSON 06

Strings

Strings store text. Template literals use backticks and let you insert expressions with ${...}. 

const name = "Alex";
const greeting = `Hello, ${name}!`;
LESSON 07

Arrays

Arrays store ordered collections. Their indexes start at zero; use methods such as push to add an item. 

const topics = ["HTML", "CSS"];
topics.push("JavaScript");
console.log(topics[0]);
LESSON 08

Objects

Objects group related values under property names. Access a property with dot notation or bracket notation. 

const learner = { name: "Alex", level: 1 };
console.log(learner.name);
LESSON 09

Conditions

Use if and else to choose which code runs based on a condition. 

const score = 85;
if (score >= 70) {
  console.log("Passed");
} else {
  console.log("Try again");
}
LESSON 10

Loops

Loops repeat a block of code. A for...of loop is a clear way to visit each value in an iterable such as an array. 

const topics = ["HTML", "CSS", "SQL"];
for (const topic of topics) {
  console.log(topic);
}
LESSON 11

Functions

Functions package reusable instructions. Parameters receive inputs; return sends a result back to the caller. 

function double(number) {
  return number * 2;
}
console.log(double(4));
LESSON 12

The DOM

The Document Object Model represents the page as objects JavaScript can inspect and change. Select an element and update its text safely. 

const heading = document.querySelector("h1");
heading.textContent = "Welcome!";
LESSON 13

Events

Events let code respond to user interactions. Register a listener on the element that should respond. 

const button = document.querySelector("button");
button.addEventListener("click", () => {
  console.log("Button clicked");
});
LESSON 14

Forms and Validation

Listen for the form's submit event, prevent a page reload when handling it in JavaScript, and check the values before using them. 

form.addEventListener("submit", event => {
  event.preventDefault();
  const formData = new FormData(form);
  console.log(formData.get("email"));
});
LESSON 15

Errors and Debugging

Read the browser console when something goes wrong. Use clear variable names, inspect values, and fix the first reported error before moving on. 

console.log("Current value:", value);
// Use a breakpoint in DevTools to pause execution.
LESSON 16

JSON

JSON is a text format for structured data. JavaScript can convert between JSON text and values with JSON.parse and JSON.stringify. 

const data = { topic: "HTML" };
const text = JSON.stringify(data);
const copy = JSON.parse(text);
LESSON 17

Asynchronous JavaScript

Promises represent work that may finish later. async and await help write asynchronous code in a readable sequence. 

async function loadData() {
  const response = await fetch("data.json");
  if (!response.ok) throw new Error("Request failed");
  return response.json();
}
LESSON 18

Modules and Next Steps

Modules split larger programs into files. Export values from one module and import them where they are used. Practice by building a small interactive page. 

// greeting.js
export function greet(name) { return `Hello, ${name}`; }
// app.js
import { greet } from "./greeting.js";

JavaScript concepts to remember

Scope
Determines where a variable can be accessed.
Parameter
A named input a function can receive.
Return value
The result a function sends back to its caller.
Promise
An object representing the eventual result of an asynchronous operation.
