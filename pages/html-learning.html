LESSON 01

HTML introduction

HTML (HyperText Markup Language) describes the structure and meaning of content on a web page. Elements tell the browser what each piece of content represents. 

<h1>A page heading</h1>
<p>A paragraph of information.</p>
LESSON 02

Your first HTML page

An HTML document begins with a doctype and contains a head for page information and a body for visible content. 

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>My first page</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
  </body>
</html>
LESSON 03

HTML elements

Most elements use an opening tag, content, and a closing tag. Some elements, such as img and br, are void elements and do not have closing tags. 

<p>This is the content inside a paragraph.</p>
<img src="photo.jpg" alt="A mountain at sunrise">
LESSON 04

Attributes

Attributes add information to an element. They are written in the opening tag, usually as a name and a quoted value. 

<a href="https://example.com" target="_blank">
  Visit the example site
</a>
LESSON 05

Headings and paragraphs

Use headings from h1 to h6 to describe the page outline. Use paragraphs for blocks of prose, and choose heading levels by meaning rather than appearance. 

<h1>Garden journal</h1>
<h2>This week</h2>
<p>The first seedlings have appeared.</p>
LESSON 06

Text formatting

Use elements that communicate meaning. For example, strong marks important content and em adds emphasis. 

<p>Remember to <strong>save your work</strong>.</p>
<p>The word <em>semantic</em> describes meaning.</p>
LESSON 07

Links

The a element makes a link. Its href value can point to another page, a section on the current page, an email address, or another destination. 

<a href="about.html">About this project</a>
<a href="#contact">Jump to contact</a>
LESSON 08

Images

Add an image with img. Provide useful alternative text with alt; use an empty value when an image is purely decorative. 

<img src="seedlings.jpg" alt="Seedlings growing in a tray">
LESSON 09

Lists

Use an unordered list when order does not matter, and an ordered list when sequence matters. Put each list item inside an li. 

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>
LESSON 10

Tables

Tables represent data organized into rows and columns. Add header cells with th and use a caption to describe the table. 

<table>
  <caption>Weekly study plan</caption>
  <tr><th>Day</th><th>Topic</th></tr>
  <tr><td>Monday</td><td>HTML</td></tr>
</table>
LESSON 11

Forms and inputs

Forms collect information. Connect each label to its input with matching for and id values, and choose an input type that suits the data. 

<form>
  <label for="email">Email address</label>
  <input id="email" name="email" type="email" required>
  <button type="submit">Subscribe</button>
</form>
LESSON 12

Semantic HTML

Semantic elements describe a region’s purpose. Use them to make page structure clearer for people, browsers, and assistive technology. 

<header>...</header>
<nav aria-label="Main navigation">...</nav>
<main><article>...</article></main>
<footer>...</footer>
LESSON 13

Audio and video

Use the native media elements when you need audio or video. Include controls so visitors can play, pause, and adjust playback. 

<video controls width="480">
  <source src="demo.mp4" type="video/mp4">
  Your browser does not support this video.
</video>
LESSON 14

Iframes

An iframe embeds another page inside the current page. Give it a descriptive title and only embed trusted content. 

<iframe src="map.html" title="Map of the campus"></iframe>
LESSON 15

Comments and entities

Comments leave notes in source code that are not displayed as page content. Character references let you write reserved characters such as angle brackets. 

<!-- Add the page introduction here -->
<p>Use &lt; and &gt; to show angle brackets.</p>
LESSON 16

Connecting CSS and JavaScript

Keep presentation and behavior in separate files as a project grows. Link a stylesheet in the head and load a script with defer. 

<link rel="stylesheet" href="styles.css">
<script src="app.js" defer></script>
LESSON 17

Accessibility basics

Use a logical heading order, descriptive link text, labels for form controls, and alternative text for meaningful images. Prefer native HTML controls when possible. 

<label for="name">Your name</label>
<input id="name" name="name" autocomplete="name">
LESSON 18

Validation and next steps

Check that tags are nested correctly, attributes are valid, and every page has a clear title. Then validate your document and test it with a keyboard and different screen sizes.

A compact guide to common HTML elements and attributes. Use these examples as a reminder, then adjust them to fit your page.

Element Purpose Example
<h1>–<h6> Headings, from the main title to lower-level sections <h1>Page title</h1>
<p> Paragraph of text <p>Hello there.</p>
<a> Link to another location <a href="page.html">Open page</a>
<img> Image; include an alt attribute <img src="cat.jpg" alt="A cat">
<ul>, <ol>, <li> Unordered and ordered lists with list items <ul><li>Item</li></ul>
<button> Interactive button control <button type="button">Open</button>
<form>, <input>, <label> Form structure and labeled user input <input id="q" type="search">
<header>, <nav>, <main>, <footer> Landmark elements that describe page regions <main>...</main>

Useful Global Attributes

id
A unique identifier for an element; useful for links and scripts.
class
A reusable name for styling or selecting a group of elements.
title
Additional advisory information; use clear visible labels for essential instructions.
lang
Declares the language of the page or an element, such as lang="en".
hidden
Indicates that an element is not currently relevant and should not be displayed.
