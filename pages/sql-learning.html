LESSON 01

SQL Introduction

SQL (Structured Query Language) is used to define, read, and change data in relational databases. Tables organize information into rows and columns.

-- A query asks the database for information
SELECT name
FROM students;
LESSON 02

SELECT

SELECT chooses columns and FROM names the table. Use * for all columns while exploring; specify columns in queries you keep.

SELECT name, grade
FROM students;
LESSON 03

DISTINCT

DISTINCT removes duplicate result rows so you can see unique values in a column or column combination.

SELECT DISTINCT city
FROM students;
LESSON 04

WHERE

WHERE filters rows before they are returned. Comparison operators include =, <>, >, and <.

SELECT name, grade
FROM students
WHERE grade >= 80;
LESSON 05

AND, OR, NOT

Combine conditions with AND and OR. Use parentheses when a query mixes them so the intended logic is clear.

SELECT name
FROM students
WHERE city = 'Manila' AND grade >= 80;
LESSON 06

ORDER BY

ORDER BY sorts the result. Use ASC for ascending order or DESC for descending order.

SELECT name, grade
FROM students
ORDER BY grade DESC;
LESSON 07

INSERT

INSERT INTO adds a row. List the target columns explicitly so the values are easy to match and maintain.

INSERT INTO students (name, city, grade)
VALUES ('Mika', 'Cebu', 91);
LESSON 08

NULL Values

NULL means a value is missing or unknown. Check it with IS NULL or IS NOT NULL, not with an equals sign.

SELECT name
FROM students
WHERE email IS NULL;
LESSON 09

UPDATE

UPDATE changes existing rows. Always check the WHERE condition carefully; without it, every row in the table can be changed.

UPDATE students
SET city = 'Manila'
WHERE student_id = 12;
LESSON 10

DELETE

DELETE removes rows. Use a precise WHERE condition and inspect matching records before deleting data.

DELETE FROM students
WHERE student_id = 12;
LESSON 11

LIMIT and TOP

Limit the number of returned rows while exploring large tables. Syntax differs between database systems: many use LIMIT, while SQL Server uses TOP.

SELECT name
FROM students
ORDER BY name
LIMIT 5;
LESSON 12

Aggregate Functions

Aggregate functions calculate one result from many rows. Common functions include COUNT, SUM, AVG, MIN, and MAX.

SELECT COUNT(*) AS student_count,
       AVG(grade) AS average_grade
FROM students;
LESSON 13

GROUP BY

GROUP BY creates groups that aggregate functions can summarize. Use HAVING to filter groups after aggregation.

SELECT city, COUNT(*) AS students
FROM students
GROUP BY city
HAVING COUNT(*) > 1;
LESSON 14

JOINs

A join combines related rows from tables. An INNER JOIN returns matching pairs; a LEFT JOIN keeps every row from the left table.

SELECT students.name, classes.title
FROM students
INNER JOIN classes
  ON students.class_id = classes.id;
LESSON 15

CREATE TABLE

CREATE TABLE defines columns and their types. Choose a primary key that uniquely identifies each row.

CREATE TABLE students (
  student_id INTEGER PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  grade INTEGER
);
LESSON 16

Data Types

Data types describe what a column stores. Common families include integers, decimal numbers, text, dates, and true/false values; exact type names vary by database.

student_id INTEGER
name VARCHAR(100)
enrolled_on DATE
LESSON 17

Constraints

Constraints protect data quality. Common examples include PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, and CHECK.

email VARCHAR(200) UNIQUE NOT NULL,
grade INTEGER CHECK (grade BETWEEN 0 AND 100)
LESSON 18

Safe Queries and Next Steps

Use parameterized queries in applications instead of joining untrusted text into SQL. Learn the SQL dialect used by your database because features and syntax can differ.

SQL concepts to remember

Row
One record in a table.
Column
A named field shared by the table’s rows.
Primary key
A column or set of columns that uniquely identifies a row.
Foreign key
A constraint that connects a value to a key in another table.
