LESSON 01

CSS Introduction

CSS (Cascading Style Sheets) describes how HTML content should look. It controls color, spacing, typography, and page layout.

p {
  color: #333;
  font-size: 1rem;
}
LESSON 02

CSS Syntax

A rule has a selector and a declaration block. Each declaration pairs a property with a value.

h1 {                 /* selector */
  color: navy;        /* property: value */
  margin-bottom: 1rem;
}
LESSON 03

Selectors

Select elements by tag, class, or id. Classes are reusable; an id should identify one unique element on a page.

p { line-height: 1.6; }
.notice { padding: 1rem; }
#main-title { color: #171918; }
LESSON 04

Colors

Set foreground colors with color and choose accessible combinations with enough contrast.

body { color: #202321; }
.button { background-color: #d8f36a; }
LESSON 05

Backgrounds

Background properties can add a color or image behind an element. Keep text readable over every background.

.card {
  background-color: #f1f2ef;
  background-image: url("pattern.png");
  background-size: cover;
}
LESSON 06

The Box Model

Each element is a box made of content, padding, border, and margin. border-box makes declared width include padding and border.

* { box-sizing: border-box; }
.card { width: 20rem; padding: 1rem; border: 1px solid #ddd; }
LESSON 07

Margins and Padding

Padding adds space inside a border. Margin adds space outside it. Use consistent spacing values to make a layout easier to scan.

.card { padding: 1.25rem; margin: 0 0 1rem; }
LESSON 08

Borders and Corners

Borders outline elements. Use border-radius to soften corners and keep edge treatments consistent.

.panel {
  border: 1px solid #dfe2dd;
  border-radius: 12px;
}
LESSON 09

Text and Fonts

Use readable font sizes, line spacing, and a clear hierarchy. A fallback font stack keeps text available if a preferred font cannot load.

body { font-family: Arial, sans-serif; }
h1 { font-size: 2rem; line-height: 1.1; }
p { line-height: 1.65; }
LESSON 10

Display

The display property affects how an element participates in layout. Flexbox and Grid are useful tools for arranging groups of elements.

.toolbar { display: flex; gap: .75rem; }
.cards { display: grid; }
LESSON 11

Positioning

Positioning controls how an element is placed. Use normal document flow by default; choose sticky or fixed positioning when the interaction needs it.

.site-header { position: sticky; top: 0; }
.badge { position: absolute; top: .5rem; right: .5rem; }
LESSON 12

Flexbox

Flexbox arranges items along one main axis. It is well suited to navigation bars, toolbars, and rows that need flexible spacing.

.nav {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 1rem;
}
LESSON 13

CSS Grid

Grid lays out content in rows and columns. Use flexible tracks so cards can adapt to the available width.

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 1rem;
}
LESSON 14

Responsive Design

Responsive layouts adapt to different screens. Start with flexible sizing and add media queries where the content needs a layout change.

.content { width: min(100% - 2rem, 70rem); margin: auto; }
@media (max-width: 600px) {
  .columns { grid-template-columns: 1fr; }
}
LESSON 15

CSS Variables

Custom properties store reusable values. Define them on a shared element and refer to them with var().

:root { --ink: #171918; --space: 1rem; }
.card { color: var(--ink); padding: var(--space); }
LESSON 16

Pseudo-classes

Pseudo-classes style elements in a state or position, such as a hovered link, a focused input, or the first item in a list.

a:hover { text-decoration: underline; }
input:focus-visible { outline: 3px solid #87945d; }
LESSON 17

Transitions

Transitions smoothly animate a property when its value changes. Keep motion short and avoid animating layout-heavy properties.

.button { transition: transform .2s ease, background-color .2s ease; }
.button:hover { transform: translateY(-2px); }
LESSON 18

Accessible Styling

Make keyboard focus visible, preserve readable contrast, and respect reduced-motion preferences. Do not use color as the only way to communicate a state.

:focus-visible { outline: 3px solid #52613b; outline-offset: 2px; }
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { scroll-behavior: auto; }
}

CSS concepts to remember

Selector
Chooses which elements a rule styles.
Specificity
Helps determine which matching rule takes precedence.
Cascade
Combines declarations according to origin, importance, and order.
Media query
Applies styles when a condition, such as screen width, matches.
